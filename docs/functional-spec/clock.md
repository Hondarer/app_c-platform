# 時計と時刻 (clock) 機能仕様

## 概要

時計と時刻は、経過時間の測定と実時刻の取得、およびその計算と整形を提供する機能です。  
対象は `cplat/clock/clock.h` と `cplat/clock/timespec.h` です。

本書は、この機能が満たす要件と、その解決策として用意した機能を説明します。  
時刻型の使用に関する規範は [cplat コーディング規範](../coding-guideline.md) の「標準時刻型」にあります。

## 解決する課題

時刻の取得 API は、プラットフォームで基準点も精度も異なります。  
Windows の実時刻は 1601 年を基準とし、Linux の実時刻は 1970 年を基準とします。  
単調増加する時計も、Linux はナノ秒、Windows は既定でミリ秒の分解能です。

時刻を保持する型にも問題があります。  
`struct timespec` のレイアウトは Linux と Windows で異なり、Windows のナノ秒フィールドは 32 ビットです。  
同じ構造体を使うつもりで書いたコードが、プラットフォーム間でバイト互換になりません。

さらに、経過時間の測定に実時刻を使うと、時刻同期による補正で差分が狂います。  
秒とナノ秒を手で加減算すると、桁上がりの正規化を忘れます。

本機能は、2 種類の時計を用途で分け、レイアウトが同じ時刻型と、その計算 API を提供します。

## 要件と機能の対応

| 要件 | 解決する機能 |
|---|---|
| 経過時間を正しく測る | 補正の影響を受けない単調増加クロック |
| 実時刻を記録し外部と突き合わせる | Unix epoch を基準とする実時刻クロック |
| 時刻をプラットフォーム間で同じ表現にする | レイアウトを固定した標準時刻型 |
| 秒とナノ秒の計算を誤らない | 正規化、加減算、比較、ミリ秒変換の API |
| タイムアウトの期限を作る | ミリ秒指定の絶対期限の生成 |
| 実時刻を人間可読の文言にする | ISO 8601 形式への整形 |
| OS の API へ時刻を渡す | ネイティブの時刻型との相互変換 |

## 種類の時計

時計は、単調増加クロックと実時刻クロックの 2 つです。

| 項目 | 単調増加クロック | 実時刻クロック |
|---|---|---|
| 基準点 | 起動時 (不定) | Unix epoch (1970-01-01T00:00:00Z) |
| 時刻同期による補正 | 受けません | 受けます (時刻が前後することがあります) |
| 値の単調増加 | 保証します | 保証しません |
| 精度 (Linux) | ナノ秒 | ナノ秒 |
| 精度 (Windows) | ミリ秒 | 100 ナノ秒 |
| 主な用途 | 経過時間の測定、タイムアウトの判定 | 実時刻の刻印 |

経過時間を測る場合とタイムアウトを判定する場合は、単調増加クロックを使います。  
実時刻クロックは時刻同期の補正でジャンプするため、差分の計算が正しく行えないことがあります。

実時刻を記録する場合と、外部のシステムと突き合わせる場合は、実時刻クロックを使います。  
ログのタイムスタンプや、外部と共有する識別子がこれに当たります。

Windows の実時刻は 1601 年を基準とする値を返すため、本機能が Unix epoch を基準とする値へ変換します。  
単調増加クロックの分解能の差も、本機能が吸収します。

## 標準時刻型

時刻の保持と受け渡しには、cplat が定義する標準時刻型を使います。  
この型は、x86-64 の Linux における `struct timespec` と同一のバイナリ レイアウトを持ちます。

Windows の `struct timespec` はナノ秒フィールドが 32 ビットでレイアウトが異なるため、そのままでは共通の表現になりません。  
OS を問わず同一の表現になる本型を、標準時刻型として使います。

絶対時刻と単調クロックの値のどちらも、この型で保持します。

ネイティブの `struct timespec` を要求する OS の API との境界では、専用の変換 API を使います。  
変換 API 以外の箇所で、ネイティブの型とのキャストや混用を行ってはなりません。

## 時刻の計算

秒とナノ秒を手で加減算すると、桁上がりの正規化を忘れて不正な値が残ります。  
本機能は、正規化、加減算、比較、ミリ秒との変換を API として提供します。

タイムアウトを扱う API へ渡す絶対期限は、現在時刻からミリ秒を加えて生成できます。  
経過時間はミリ秒の差分として取得できます。

実時刻は、UTC への分解と、ISO 8601 形式の文字列への整形ができます。  
整形は UTC 表記とローカル時刻表記の両方を提供します。

## 適用範囲外

次の項目は本機能が扱いません。

- タイム ゾーンのデータベースと、任意のタイム ゾーンへの変換。ローカル時刻は OS の設定に従います。
- 暦の計算。日付の加減算や営業日の判定は提供しません。
- 高分解能タイマーによる周期実行。

## 前提と制約

単調増加クロックの基準点は不定です。  
値そのものに意味はなく、2 つの値の差だけが有効です。

実時刻クロックは時刻同期によって前後することがあります。  
変更の前後関係を判定する用途には使わないでください。

Windows の単調増加クロックはミリ秒の分解能です。  
これより細かい経過時間の測定はできません。

標準時刻型のレイアウト互換は x86-64 を前提とします。

# cplat 機能仕様

## この文書群の役割

`functional-spec/` は、利用側または上位設計から見た cplat の責務を、機能カテゴリごとに説明する文書群です。  
cplat が解決する課題、満たす要件、外部から観測できる振る舞い、前提、保証範囲、適用範囲外を定めます。

機能仕様は、API 設計、実装設計、実装、テストへ渡す入力です。  
記載範囲、章立て、要件 ID と UUID の運用は [cplat 機能仕様の記載規範](../functional-spec-guideline.md) に従います。

## 文書の位置付け

機能仕様は、関数の一覧、実装方式、テスト方法を扱いません。  
下流成果物は、設計判断または検証対象の根拠を示す必要がある場合に、機能仕様の要件 ID と UUID を参照します。

同じ階層にある機能仕様は、責務の境界または選択方法を説明する場合に相互参照します。

## 変更時の扱い

cplat の機能、外部から観測できる振る舞い、前提、保証範囲、適用範囲外を変更する場合は、対応する機能仕様を先に変更します。  
要件 ID と UUID の追加、維持、廃止は [cplat 機能仕様の記載規範](../functional-spec-guideline.md) に従います。

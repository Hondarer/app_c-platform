# 正規表現 (regex) 機能仕様

## 概要

正規表現は、UTF-8 の文字列に対する照合、置換、反復列挙、分割を、Linux と Windows で共通の文字モデルとして提供します。

## 解決する課題

正規表現の利用可否、文字幅、ロケールによる文字分類、複雑なパターンの限界は、実行環境によって異なります。  
同じ UTF-8 の入力を扱っても、文字の数え方とマッチ位置の単位が異なれば、利用側が切り出す範囲も変わります。

一致しなかった結果と、パターンまたは入力を処理できなかった失敗も区別する必要があります。  
本機能は、文字モデル、オフセット、失敗の意味を cplat の仕様として固定します。

## パターンと文字モデル

既定のパターン文法は ECMAScript とし、POSIX の基本正規表現と拡張正規表現も選択できます。  
大文字小文字を無視する指定と、捕捉結果を省略する指定を使用できます。

照合では UTF-16 コード単位を一文字として扱います。  
ASCII と基本多言語面の文字は一文字、基本多言語面の外にある文字は二文字として扱います。

| 文字の範囲 | 例 | 照合上の文字数 |
|---|---|
| ASCII | `a` | 1 |
| 基本多言語面 | `あ`、`漢` | 1 |
| 基本多言語面の外 | 絵文字、CJK 拡張 B 以降 | 2 |

返す位置は、UTF-8 入力の先頭から数えたバイト位置です。  
マッチ境界がサロゲート ペアの内側になる場合は、開始位置を前方、終了位置を後方のコード ポイント境界へ広げます。  
返した範囲を切り出した結果が、不正な UTF-8 になることはありません。

## 照合、列挙、置換、分割

部分一致は、指定した開始位置以降で最初に一致する範囲を返します。  
全体一致は、入力全体がパターンに一致するかを返します。

一致が存在しない場合も照合処理自体は完了しているため、処理の失敗とは別の結果として返します。

反復列挙は、一致を入力の先頭から順に返します。  
空文字列へ一致するパターンでも、同じ位置を繰り返して処理が停止しない状態にはなりません。

置換は、一致した範囲を指定した内容へ置き換えます。  
分割は、一致した範囲を区切りとして、入力上の各範囲を返します。

## 失敗の通知

次の状態を区別して通知します。

- 引数または指定の組み合わせが不正
- パターンの文法が不正
- パターンまたは入力が不正な UTF-8
- 出力先の容量が不足
- 入力の長さまたは照合の複雑度が処理可能な範囲を超過
- 処理に必要なメモリを確保できない

照合の複雑度に対する限界は、プラットフォームによって異なる場合があります。  
限界を超えた場合は、照合結果を返さず、処理可能な範囲の超過として通知します。

## 適用範囲外

- Unicode 全体の大文字小文字変換
- Unicode の文字カテゴリに基づく文字クラス
- Unicode 正規化
- POSIX の改行指定と同じ意味を持つ複合指定
- 信頼できない利用者が任意に作成したパターンに対する実行時間の保証

## 前提と制約

パターンと入力は、正しい UTF-8 である必要があります。

大文字小文字を無視する照合は ASCII の範囲だけを同一視します。  
文字クラスも ASCII の定義を使用します。

Unicode 正規化を行わないため、同じ表示になる異なるコード ポイント列を同一とは扱いません。

処理時間が入力長に対して急増するパターンがあります。  
外部から受け取った信頼できないパターンを、制限なしに実行する用途には使用できません。

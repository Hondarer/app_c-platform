# Win32 UTF-8 ラッパー (win32) 機能仕様

## 概要

Win32 UTF-8 ラッパーは、UTF-8 の文字列を使用する cplat と Win32 の文字列境界を変換する Windows 専用機能です。  
文字列を扱う Win32 API を、UTF-8 の入出力として利用側へ提供します。

## 解決する課題

Win32 のナロー文字列は現在のコード ページで解釈されるため、UTF-8 の非 ASCII 文字をそのまま渡すと内容が変わります。  
ワイド文字列を使用する場合は、呼び出しのたびに UTF-8 との相互変換と変換領域の管理が必要です。

本機能は、UTF-8 と Win32 の文字列境界を一か所へまとめます。

## 対象の範囲

ファイル、名前付きパイプ、モジュール、コンソール、ボリューム、ライブラリ、プロセス、サービス制御のうち、文字列を入力または出力に持つ Win32 API を対象とします。

文字列を入力する場合は、UTF-8 から Win32 のワイド文字列へ変換して処理します。  
文字列を出力する場合は、Win32 のワイド文字列から UTF-8 へ変換して返します。

Linux では本機能を提供しません。

## 適用範囲外

- Win32 の結果体系を cplat 共通の結果体系へ変換すること
- 現在のコード ページを使用するナロー文字列の提供
- 文字列を扱わない Win32 API のラップ
- Win32 API を Linux でも使用できる機能へ抽象化すること

## 前提と制約

利用側が渡す文字列は UTF-8 である必要があります。

本機能は Win32 固有の結果体系を維持します。  
利用側は、対象の Win32 API と同じ方法で結果を判定します。

ワイド文字列のまま処理が完結し、UTF-8 との境界がない処理は本機能の対象ではありません。

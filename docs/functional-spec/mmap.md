# メモリ マップド ファイル (mmap) 機能仕様

## 概要

メモリ マップド ファイルは、ファイルの内容をプロセスのアドレス空間へ対応付けて参照する機能です。

## 解決する課題

ファイルのオープン、サイズ調整、アドレス空間への対応付け、反映、解放は、Linux と Windows で手続きが異なります。  
本機能は、ファイルと対応付けられた領域の寿命を一つにまとめます。

## 対応付けと解放

読み取り専用では、既存のファイル全体を読み取り可能な領域として対応付けます。  
ファイルが存在しない場合は成功しません。

読み書きでは、ファイルが存在しない場合に指定した長さで新しく作成します。  
既存のファイルを開く場合は、現在のファイルの長さを使用します。

後処理は、アドレス空間との対応付けと、ファイルを保持する資源をまとめて解放します。

## 書き込みの反映

読み書き可能な領域への変更は、明示的にローカル ファイル システムへ反映できます。  
反映の完了は、遠隔ストレージや物理媒体への永続化までは保証しません。

## 適用範囲外

- ファイルの一部分だけを指定する対応付け
- 対応付け後のファイル長の変更
- 長さが 0 のファイル
- ファイルに対応付けない匿名マッピング
- 対応付けた領域への排他制御
- 対応付けたデータ形式の整合性検査

## 前提と制約

対応付けている間、利用側は対象ファイルの長さを変更してはなりません。

複数の実行主体から同じ領域へアクセスする場合は、利用側が同期方法、その識別、所有権、寿命を管理する必要があります。

ネットワーク ファイル システムでは、プロセス間、特にホストをまたぐ一貫性を保証しません。

## 選択の指針

逐次的な読み書きには C ランタイム抽象のファイル操作を使用します。  
ファイル内の領域をランダムに参照する場合や、ファイル上の構造を直接参照する場合に本機能を使用します。

複数の実行主体から同じ領域へアクセスする場合は、入出力方式とは独立して同期方法を選択します。

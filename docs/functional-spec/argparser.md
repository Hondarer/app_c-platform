# コマンド ライン引数解析 (argparser) 機能仕様

## 概要

コマンド ライン引数解析は、`argc` と `argv` を、登録した定義に従って型付きの値へ振り分ける機能です。  
対象は `cplat/argparser/argparser.h` が公開する `cplat_argparser_*` の一群です。

本書は、この機能が満たす要件と、その解決策として用意した機能を説明します。  
ユース ケース別の使い方は `prod/libsrc/cplat/argparser/README.md`、明示ハンドル API は同ディレクトリの `argparser.internal.md` を参照してください。

## 解決する課題

引数の解析を自前で書くと、次の処理を毎回繰り返します。

- 短い名前と長い名前の両方を突き合わせる
- `--option value` と `--option=value` の両方の書き方を受け付ける
- 値を整数へ変換し、失敗と範囲超過を検出する
- 必須の項目が指定されたかを確認する
- 使い方の説明文を、登録した定義と食い違わないように書く

さらに、誤りには 2 種類あります。  
利用者が誤った引数を渡した場合と、プログラムが登録の仕方を誤った場合です。  
前者は利用者へ使い方を示し、後者は開発中に気付く必要があります。  
これらを同じ経路で通知すると、どちらの誤りか分かりません。

本機能は、定義の登録、解析、参照の 3 段階に分け、2 種類の誤りを別々に通知します。

## 要件と機能の対応

| 要件 | 解決する機能 |
|---|---|
| 引数を型付きで受け取る | フラグ、整数、文字列を型ごとに登録 |
| 短い名前と長い名前の両方を使う | 登録時に両方を指定 |
| 同じオプションを複数回指定する | 出現順に配列へ格納する登録 |
| 位置引数を扱う | 登録順に割り当てる位置引数と、末尾の可変長位置引数 |
| 必須の指定漏れを検出する | 必須の指定と、解析時の検査 |
| 利用者の誤りを説明する | 誤りの種類、対象、位置と、メッセージの出力 |
| 登録の誤りを開発中に見つける | 登録時の誤りを別に数え、別に出力 |
| 使い方の説明文を保つ | 登録した定義からの使い方の生成 |
| ハンドルを持たずに使う | プロセス共有のパーサーを暗黙に使う API |
| 複数のパーサーを同時に扱う | 明示ハンドルの API |

## 対応する構文

| 構文 | 例 |
|---|---|
| フラグ | `-v` / `--verbose` (出現回数を格納) |
| 値付きオプション | `-o value` / `--option value` / `--option=value` |
| 複数回指定できる値付きオプション | 上記の繰り返し (出現順に配列へ格納) |
| 位置引数 | 登録順に割り当て |
| 可変長位置引数 | 位置引数列の末尾で複数の値を配列へ格納 |
| 負の位置整数 | 次の位置引数が整数型の場合、`-1` などを位置引数として割り当て |

次の構文には対応しません。

- 短いオプションの連結 (`-abc`)
- 1 つのオプションに複数の値を続ける方式 (`--option value1 value2 value3`)
- `--` 以降を無条件で位置引数として扱う慣習

## 利用の流れ

利用は、初期化、登録、解析、参照の順に進みます。

登録では、短い名前、長い名前、説明、格納先を指定します。  
解析の結果は、登録時に指定した格納先へ直接書き込みます。  
呼び出し側は、解析後に個別の取得 API を呼ぶ必要がありません。

既定値は、解析の前に格納先へ設定します。  
指定されなかった項目の格納先は書き換えないため、設定した既定値が残ります。

通常のアプリケーションは、プロセス共有のパーサーを暗黙に使う API だけで完結します。  
パーサーの実体はプロセスの正常終了時に自動で解放するため、明示的な解放は不要です。  
複数のパーサーを同時に扱う場合は、明示ハンドルの API を使います。  
主にテストで使う形態です。

## 種類の誤り

登録の誤りは、解析を始める前に検出します。  
名前の重複や不正な指定など、プログラムの側の誤りです。  
件数を数え、まとめて出力できるため、開発中に気付けます。

利用者が渡した引数の誤りは、解析の結果として通知します。  
未登録のオプション、値の欠落、値を取らない項目への値、整数として解釈できない値、範囲超過、必須の指定漏れ、単数指定の項目の重複、引数の個数超過を、それぞれ別の結果コードで区別します。

誤りの対象となった項目名と、引数配列上の位置も取得できます。  
メッセージの文字列を取得する API と、指定したストリームへ出力する API の両方を提供します。

使い方の説明文は、登録した定義から生成します。  
説明文を別に書き起こさないため、定義との食い違いが起きません。

## 適用範囲外

次の項目は本機能が扱いません。

- サブコマンド。コマンドごとに異なる引数の集合を持つ構造は扱いません。
- 設定ファイルや環境変数との統合。
- 引数の相互依存の検証。ある項目が指定されたときだけ別の項目を必須にする、といった条件は呼び出し側で行います。
- 補完スクリプトの生成。

## 前提と制約

登録は解析より前に行ってください。

格納先の寿命は、解析と参照の間、有効である必要があります。

暗黙のパーサーはプロセスで共有します。  
複数のスレッドから同時に登録や解析を行う場合は、呼び出し側で直列化してください。

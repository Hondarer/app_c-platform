# コンソール (console) 機能仕様

## 概要

コンソールは、プログラムが接続している端末を、UTF-8 と ANSI エスケープ シーケンスを扱える状態にそろえる機能です。  
Windows で権限を昇格したプロセスを、昇格前の親コンソールへ再接続する機能も提供します。

## 解決する課題

Linux の端末と Windows のコンソールでは、UTF-8 と ANSI エスケープ シーケンスを利用するために必要な設定が異なります。  
Windows では、プロセスの文字コード設定だけでは、接続先コンソールの入出力を UTF-8 にできません。

権限を昇格してプロセスを再起動した場合、昇格後のプロセスは親のコンソールを引き継げないことがあります。  
本機能は、端末設定と親コンソールへの再接続を、利用側から同じ手続きで扱えるようにします。

## 初期化と後処理

Windows では、コンソールの入力と出力の文字コードを UTF-8 に設定し、標準出力と標準エラー出力の仮想端末処理を有効にします。  
すでに目的の状態である設定は変更しません。

変更前の状態を保持し、後処理で元に戻します。  
初期化を複数回行っても追加の変更は行わず、初期化していない状態の後処理も受け付けます。

Linux では、初期化と後処理によって端末状態を変更しません。

## 端末でない場合の扱い

標準出力がパイプまたはファイルへ接続されている場合は、端末に対する設定を変更しません。  
標準入力、標準出力、標準エラー出力の接続先自体も変更しません。

## 親コンソールへの再接続

Windows では、権限昇格時に渡された親プロセスと親コンソールの情報がある場合、親コンソールへ接続し直します。  
再接続後は、標準入力、標準出力、標準エラー出力を親コンソールへ接続します。

引き継ぎ用の情報は、通常のコマンド ライン引数として後続処理へ渡さないよう取り除きます。  
Linux では再接続を行わず、再接続していない結果を返します。

## 適用範囲外

- 標準出力または標準エラー出力への書き込み処理
- 端末サイズの取得と画面上の入力欄の制御
- 代替画面バッファーへの切り替え
- 親プロセスとの確実な結果データの受け渡し

## 前提と制約

Windows では、利用側のプロセスが UTF-8 を ANSI コード ページとして使用する設定を持つ必要があります。  
プロセスの文字コードとコンソールの文字コードは別々に設定されます。

親コンソールへの再接続は、権限昇格時に親の情報が渡された場合だけ行います。  
再接続後の出力が常に成功することは保証しません。  
確実な結果の受け渡しが必要な場合は、実行時支援が提供する結果受け渡しを使用します。
